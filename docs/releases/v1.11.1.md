# PnP Bridge 1.11.1

Corrected guidance for the AAA new-style conversion in Day-N templates.

## Fixed

- **The interactive-prompt hint now gives the right command sequence.** Per
  Cisco's own IOS-XE 17.x documentation, `authentication display new-style` is a
  **privileged-EXEC** command — Catalyst Center runs template lines in config
  mode, where IOS rejects it with `% Invalid input detected`. The hint (and the
  recommended template block) is now the one-shot converter run in EXEC mode
  with its confirmation answered:

  ```
  #MODE_ENABLE
  #INTERACTIVE
  authentication convert-to new-style<IQ>continue<R>yes
  #ENDS_INTERACTIVE
  #MODE_END_ENABLE
  ```

## Upgrade notes

- No schema change. `git pull && make image`, recreate the container.
- The corresponding template change is in `IT_DayN_Port_Template` (see the
  updated template shared alongside this release).
