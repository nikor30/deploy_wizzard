# PnP Bridge 1.20.1

## Fixed

- **The `NCHS20057` hint named the wrong commands.** 1.20.0 blamed AAA/TACACS.
  A Day-0 onboarding template can trigger the same conflict without containing a
  single AAA line: **SNMP and syslog are Design → Network Settings items too**,
  so `snmp-server community`, `snmp-server trap-source`, `logging host`,
  `logging trap` and `logging source-interface` conflict just as much.

  The hint now names the full set — AAA/TACACS/RADIUS, SNMP, syslog, NTP, DNS,
  DHCP — and points at Catalyst Center's **Provision Conflicts** tab on the
  template, which lists the actual offending commands rather than leaving it to
  guesswork.
