# PnP Bridge 1.19.2

## Changed

- **A provisioning failure whose task tree explains nothing now logs the tree
  verbatim.** Catalyst Center's *"Batch Operation failed … Submit a GET task
  tree request using the parent taskId"* is only actionable if the tree actually
  says something; when it does not, the parent task and the full tree are
  written to the Logs page at WARNING (context keys `task` and `task_tree`).

  The evidence is captured automatically — no need to turn on HTTP trace and
  find the request by hand.

## Upgrade notes

- No schema change. `git pull && make image`, recreate the container.
