# PnP Bridge 1.15.0

## Added

- **Settings → Access ports** — choose where the Day-N `ACCESS_PORTS` variable
  comes from:

  - **From NetBox** (default): physical ports that are not management ports and
    that NetBox does not show as cabled to another device. Uplinks are excluded
    by what they are connected to rather than by their name, so an uplink on a
    front-panel port is correctly skipped and a front-panel port on an expansion
    module is correctly included.
  - **Let the template decide**: `ACCESS_PORTS` is left empty and the template
    falls back to its own on-device `$__interface` loop. Use this when NetBox
    cabling is not maintained — or later, if Catalyst Center gains a native way
    to apply port configuration.

  In "let the template decide" mode the variable is blank rather than missing,
  so the template's `#if` selects the fallback and the wizard shows the variable
  as unresolved instead of silently pushing a list you opted out of.

## Upgrade notes

- No schema change. `git pull && make image`, recreate the container.
- The matching `IT_DayN_Port_Template` rewrite is shared alongside this release;
  it handles both modes, so you can switch the setting without editing it again.
