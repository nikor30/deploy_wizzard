# PnP Bridge 1.7.0

Choose which Catalyst Center PnP device states the wizard lists.

## New

- **PnP device state filter (Settings → Credentials → "PnP device states").**
  Wizard step 1 used to list a fixed set of states. You can now pick exactly
  which ones to see:
  - `Unclaimed` — new devices waiting to be claimed
  - `Planned` — claimed, config not applied yet
  - `Onboarding` — currently provisioning
  - `Error` — previous claim failed
  - `Provisioned` — already onboarded (useful for troubleshooting)
  - `Deleted` — removed in Catalyst Center

  The first four stay the default, so nothing changes until you widen the
  selection. Catalyst Center is only polled for the states you ticked, and at
  least one state must remain selected.

## Upgrade notes

- No schema change (the setting lives in the existing key/value settings table).
