# PnP Bridge 1.22.1

## Fixed (documentation)

- **"Assign to site" no longer claims it delivers AAA.** 1.21.0 said Device
  Controllability pushes the site's network settings — including AAA — when a
  device is assigned. Cisco's Device Controllability page lists what assignment
  actually pushes: wired endpoint data collection, controller certificates, SNMP
  trap and syslog server definitions, application visibility and QoS, and
  wireless telemetry. **AAA, TACACS and RADIUS are not among them**, and the
  same page states the telemetry settings are pushed "when the device is
  provisioned".

  The option's description now says what it really does: attaches the device and
  pushes SNMP traps, syslog and telemetry — not AAA/TACACS/RADIUS, which come
  from provisioning.

  This confirms the 1.22.0 default, **Provision wired device**, is the correct
  choice for getting AAA onto a switch.
