# PnP Bridge 1.25.1

## Fixed

- **The access-port/ISE template now runs after the uplink template.**

  The live Day-N failure shows the port template reaching IOS's interactive
  legacy-AAA conversion prompt. Catalyst Center rejects that member as invalid
  CLI, after which later members only report collateral SSH timeouts. Safe
  templates still run first, but disruptive members are now split into two
  groups: uplink/interface/channel configuration, followed by access-port,
  dot1x and ISE configuration last.

  This lets VLAN and uplink configuration land before the access template can
  interrupt the temporary PnP management path. Ordering cannot answer an IOS
  interactive prompt: the Catalyst Center access-port template must wrap the
  prompting command in its supported `#INTERACTIVE` block, as named in the
  wizard's failure message.

## Upgrade notes

- No schema change. Rebuild and recreate the container after pulling this
  release.
