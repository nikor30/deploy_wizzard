# PnP Bridge 1.23.1

## Fixed

- **A Catalyst Center role change now takes effect immediately.** A CCC token
  carries the account's role at the moment it was issued, and PnP Bridge caches
  one for ~55 minutes. Granting the API account provisioning rights would
  therefore appear to change nothing until the cached token expired.

  The client now forces one token reissue on **403** as well as 401. A 403 that
  survives a fresh token is reported as what it is — the account's role, not a
  stale token — naming System → Users & Roles.

## Upgrade notes

- No schema change. `git pull && make image`, recreate the container.
- Recreating the container also discards any cached token, so a role change is
  picked up either way.
