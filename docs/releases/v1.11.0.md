# PnP Bridge 1.11.0

Webhook TLS toggle, a clearer settings menu, and the gateway from NetBox.

## New

- **Verify TLS certificate — ISE webhook.** The webhook block now has the same
  TLS toggle the Catalyst Center and NetBox blocks already had. Turn it off for
  an ISE helper behind a self-signed or private-CA certificate, which otherwise
  fails delivery with `certificate verify failed: unable to get local issuer
  certificate`. (The backend already honoured the setting; only the switch was
  missing.)

- **Default gateway taken from NetBox.** When a management VLAN is selected, the
  Day-0 gateway is now the address NetBox documents for that VLAN — the IP in
  the VLAN's prefix whose DNS name or description says "gateway" — instead of
  guessing the first host of the subnet. It stays an editable field so you
  confirm it. If no address is marked, or two are, the first-host guess is kept
  rather than picking the wrong gateway and stranding the device.

  The lookup runs only for the VLAN you actually picked (a site can carry dozens
  of VLANs) and is cached per VLAN within a job.

## Changed

- The **Credentials** entry in the settings menu is now called **Settings**.
  The page and its URL are unchanged.

## Upgrade notes

- No schema change. `git pull && make image`, recreate the container.
- Re-run "Resolve variables" on a job sitting on step 3 to pick up the NetBox
  gateway.
